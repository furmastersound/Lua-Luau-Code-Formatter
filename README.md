## How to Use

Format a file:

```bash
stylua script.lua
```

Format a folder:

```bash
stylua src/
```

Check formatting without changing files:

```bash
stylua --check .
```

Use a `stylua.toml` file to configure formatting preferences for your project.

Editor integrations can format Lua and Luau files or selected code through StyLua.
